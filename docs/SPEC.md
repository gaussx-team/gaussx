## 1. 데모 범위 (약 2분)
관리자 태깅 → 작업반장 카드 전송·확인 → 쓰러짐 감지(자동 + 3초 수동 SOS) → 로봇 즉시 자동 출동 → 관제 확인(기록)

| 구분 | 내용 |
|---|---|
| 포함 | 로그인 없음 · 기기 ID(`helmet-01`) · 작업허가서 PDF 첨부 · 자동 감지 + 수동 SOS · 로봇 자동 출동 |
| 제외 (로드맵) | 실제 비콘 하드웨어 · 실시간 정밀 위치 · 스마트 글래스 · 번역 · 일일 리포트/PDF 다운로드 |
| 보류 (개발하며 결정) | 구역 색·사람 점 표시 · 사고 시 태그 재표시 · 구역 폴리곤 저장 방식 |
