# GaussX frontend (데모)

Next.js 16 (App Router) · React 19 · Tailwind v4 · TypeScript

## 실행

```bash
npm install
cp .env.example .env.local   # 비워두면 목업 API 사용
npm run dev                  # http://localhost:3000
```

휴대폰으로 카드 화면 테스트 (같은 와이파이):

```bash
npm run dev -- -H 0.0.0.0    # 휴대폰에서 http://<노트북 IP>:3000/card
```

> 가속도 센서(쓰러짐 자동 감지)는 **https** 에서만 동작해요. http 로는 SOS 버튼만 테스트하고,
> 자동 감지는 `npx next dev --experimental-https -H 0.0.0.0` 또는 Vercel 배포 주소로 확인하세요.
> iPhone 은 카드 화면의 "센서 권한 요청" 버튼을 눌러야 해요.

## 화면

| 경로 | 화면 | 누가 |
|---|---|---|
| `/` | 대시보드 (오늘 현황 · 진행 중 작업 · 알림 · 구역 상태) | 원청 담당자 |
| `/control` | 관제 (평면도 · 알림 · 로봇 · 오늘 타임라인) | 관제 |
| `/admin/works` | 작업 지시 목록 (진행 중/종료/전체 · 검색) | 원청 담당자 |
| `/admin/works/new` | 새 작업 지시 (구역 → 태그 자동 → 전송) | 원청 담당자 |
| `/admin/works/[id]` | 작업 지시 상세 (작업지시서 · 진행 단계 · 확인 결과 · 알림 · 기록 · 카드 미리보기) | 원청 담당자 |
| `/admin/tags` | 위험 태그 등록 (템플릿 → 확인 항목 자동) | 원청 담당자 |
| `/robot` | 로봇 — 운영 상태(출동 대기/충전 중/점검 중/연결 끊김)·배터리·출동 기록 | 원청 담당자 |
| `/history` | 이력 (날짜 · 종류 · 구역 · 작업 · 검색 필터, CSV) — 필터가 주소에 남아 공유 가능 | 누구나 |
| `/card?device=helmet-01` | 작업 카드. 휴대폰은 전체 화면, 웹(넓은 화면)은 휴대폰 틀 안에 표시 | 작업반장 |
| `/card?work=3&preview=1` | 카드 미리보기 (읽기 전용, 기록 안 남김) | 원청 담당자 |
| `/demo` | **시연 모드** — 작업자 휴대폰 화면 + 시나리오 진행 + 무대 트리거 + 리셋 (서비스 메뉴에는 없음) | 발표자 |

시연은 `/demo` 에서 진행해요. 서비스 화면(대시보드·관제 등)에는 시연용 버튼이 없어요.
발표 화면 구성 예: 노트북 = `/demo`, 무대 화면 = `/control`, 작업반장 = 실제 휴대폰 `/card`.

## 목업 API → NestJS 전환

지금은 `src/app/api/*` (Next route handler) + `src/lib/server/store.ts` (메모리 저장소)가 백엔드 역할을 해요.
노트북 한 대에서 `npm run dev` 만 켜면 휴대폰·관제 화면이 같은 데이터를 봐요. (서버를 끄면 초기화)

> 목업 데이터는 dev 서버 메모리에 있어요. 서버를 끄면 초기화되고, 저장소 모양(`STORE_VERSION`)이 바뀌면 자동으로 다시 만들어져요.

백엔드가 준비되면:

1. `.env.local` 에 `NEXT_PUBLIC_API_BASE_URL=http://<백엔드 주소>` 입력
2. `src/app/api`, `src/lib/server` 폴더 삭제
3. 응답 모양은 `src/lib/types.ts` 기준 — 다르면 `docs/api.md` 에서 먼저 맞추기

## 목업에 들어간 규칙 (백엔드도 같게)

- 첫 확인 = 체크인, 확인은 되돌릴 수 없음
- 필수 항목을 다 확인해야 "작업 시작"
- 측정값이 정상 범위를 벗어나면 거부 + 관제에 알리라는 안내
- 쓰러짐 알림과 **동시에** 로봇 자동 출동 (관제 "확인했어요"는 기록용)
- 알림 구역: 직접 지정 → 그 기기의 진행 중 작업 구역 → 불명(출동 안 함)
- 자동 감지 오작동은 10초 안에 작업자가 "괜찮아요"로 취소 가능
- 로봇이 출동할 수 없으면(충전·점검·연결 끊김·다른 출동 중·구역 불명) 알림은 `no_robot` 상태가 되고, 관제가 "안전관리자 출동 지시"를 누르면 그 시각이 기록됨
- 로봇이 출동 대기가 아니면 대시보드에 미리 경고
- 로봇 속도 0.45 m/s, 구역별 경로는 `store.ts` 의 `PATHS`
